### 🏫 [School Reports API](https://github.com/broislerdev/school-reports-api)

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat&logo=fastapi&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat&logo=postgresql&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat&logo=supabase&logoColor=white)

API REST desenvolvida com **Python**, **FastAPI**, **PostgreSQL** e **Supabase** para gerenciamento de denúncias escolares anônimas.

O projeto permite que estudantes relatem situações como bullying, violência e outros problemas dentro do ambiente escolar de forma mais segura. As denúncias são classificadas automaticamente com apoio de IA e notificadas à coordenação da escola por email.
Além da parte técnica, esse projeto busca destacar a importância de canais de denúncia nas escolas, ajudando alunos que muitas vezes deixam de pedir ajuda por medo, vergonha ou falta de confiança.
